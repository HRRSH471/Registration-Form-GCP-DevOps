# Registration Form Application on GCP using Terraform

## Project Overview

This project demonstrates a complete DevOps deployment of a Flask Registration Application on Google Cloud Platform using Infrastructure as Code (Terraform).

The project includes:

- Terraform Infrastructure
- Custom VPC
- Public and Private Subnets
- Cloud NAT
- Firewall Rules
- Frontend VM
- MongoDB VM
- Flask Application
- Gunicorn
- Nginx Reverse Proxy
- Cloud DNS
- HTTPS using Let's Encrypt SSL
- GitHub Repository
